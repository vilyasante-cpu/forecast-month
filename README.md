# Прогноз месяца - скилл для любого ИИ-чата

Бесплатный мини-скилл: автопуть опросник → срез → три сценария → диагностика
(Worst / Base / Upside + «кому звонить»).

Автор: Рафаэль Вильясанте.  
Работает в ChatGPT, Claude, Cursor, Gemini и любом другом чате, куда можно
вставить текст инструкций.

В репозитории нет секретов, паролей, webhook и ключей. Только метод.

## Файлы

| Файл | Зачем |
|------|--------|
| [SKILL.md](SKILL.md) | Инструкция для ИИ: автопуть, канон, опросник |
| [пусковая-формула.md](пусковая-формула.md) | Шаблон ответа после пути |

## Запуск за 1 минуту (ChatGPT / Claude / любой чат)

1. Открой [SKILL.md](SKILL.md) → скопируй весь текст.
2. Вставь в новый чат первым сообщением (или в custom instructions / system prompt).
3. Напиши: `прогноз месяца`
4. Агент сам ведёт блоки опросника. Отвечай по одному шагу.
5. В конце - формула, три сценария, диагностика и рычаги.

Если удобнее - прикрепи оба файла к чату (где чат это умеет) и напиши то же.

## Cursor (по желанию)

1. Скачай репозиторий или папку.
2. Положи в проект: `.cursor/skills/forecast-month/`
   (файлы `SKILL.md` и `пусковая-формула.md` внутри).
3. В чате агента: `прогноз месяца`

Можно и без установки: просто вставь `SKILL.md` в чат Cursor, как в ChatGPT.

## Что получишь

- Определение факта месяца под твой бизнес
- Коэффициенты `fade` и `w_factor`
- Worst / Base / Upside на срез
- Диагностику рядом с цифрой (хвосты, опора, тихие «свои»)
- 3 рычага на месяц и сигналы на неделю

## Чего здесь нет

- Нет подключений к CRM и учётным системам
- Нет просьб отдать доступы или токены
- Нет обещаний «вырастим выручку»
- Нет чужих порогов и отраслевых бенчмарков «из воздуха»

Цифры считаются только из того, что ты сам вводишь в чат.
