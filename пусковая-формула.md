# Пуск-формула (шаблон выдачи)

Заполняет ИИ после автопути (опросник → срез → счёт → диагностика).
Пустые поля не оставлять: либо ответ пользователя, либо явно `не задано → default`.
Не просить секреты, пароли, токены - только цифры факта и календарь.

## 3. Формула (подставленная)

```
pace      = MTD / B_elapsed
P_hold    = pace × B_full
P_fade    = pace × {fade} × B_full
Base      = median(P_fade, P_hold)
Worst     = MTD + pace × {w_factor} × B_remaining
Upside    = P_hold
```

Carry-in: если есть - показать `MTD_чистый = MTD − carry_in` и считать pace
от чистого **или** явно оставить pace от полного MTD с пометкой риска
завышения (выбор пользователя зафиксировать одной строкой).

Запрет: не использовать median cumshare / «как обычно к дню N» как Base.

## 10. Цикл улучшения

После 2–3 срезов:
- факт финиша vs Base / Worst / Upside;
- подкрутить только `fade` и/или `w_factor`;
- каркас формулы не менять;
- не пересчитывать вилку суммой ожиданий по клиентам.

Запись: «в следующий раз fade = …, w_factor = …, потому что …».
